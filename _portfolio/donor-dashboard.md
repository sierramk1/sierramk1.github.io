I helped develop an interactive donor profiling dashboard in Apache Superset for the Ann Arbor Hands-On Museum through STATCOM (Statistics in the Community).

The dashboard uses professional and organizational data to help visualize donor profiles and identify patterns that may support the museum's fundraising efforts. We developed interactive visualizations and filters that allow users to explore donor characteristics and affiliations.

**Tools:** Apache Superset, data visualization, data analysis
