OptiLearn is an interactive web application designed to help students better understand optimization algorithms through visualization and hands-on exploration.

The application allows users to select optimization methods, input functions or data, adjust parameters, and step through algorithm iterations. Animated plots and pseudocode views help connect the mathematical concepts behind optimization algorithms with their computational behavior.
